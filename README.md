Работа приложения осуществляется согласно ТЗ. `<body>` у нас пустой, а генераци всех эелментов осуществляется через js. Основные элементы генерируются в файлах папки page, а остальные по мере надобности в других логиках. Навигация такая:
- `data` - данные карточек. Допольно скуно на самом деле. Я сперва думал заменить сердечки и вопросики на полноценные картинки, а потом решил, что смотрится очень симпатично.
- `game` - основная логика игры. Тут все файлы, связанные с геймплеем.
- `modal` - тут один файл с модалкой. Там довольно простая логика, поэтому не стал дробить. Хотя для красоты стоило бы. Кстати, модалка общая, меняется только отображаемый контент.
- `page` - генерация основных элементов. Я уже говорил? Ну да.
- `sub` - всякие вспомогательные штуки.
